FINESSE HAIR SALON - COLLEGE WEB DEVELOPMENT PROJECT

Technology:
- HTML5
- CSS3
- CSS Grid and Flexbox
- Responsive Media Queries
- No JavaScript
- No Bootstrap
- No PHP / MySQL
- No frameworks

Pages:
index.html, about.html, services.html, pricing.html, gallery.html,
team.html, appointment.html, contact.html, offers.html, faq.html

How to run:
1. Extract the Finesse-Hair-Salon folder.
2. Open index.html in Chrome/Edge/Firefox.
3. Use the navigation menu to demonstrate all pages.

Note:
The demonstration uses publicly hosted Unsplash image URLs so the project can show realistic visuals without JavaScript or frameworks. For an offline submission, download replacement images into the images folder and update the image paths.
Forms use HTML5 validation only and do not submit data to a database.
